# 龙女仆模型 · 三元素 × 五阶段（YSM）

为 Minecraft 模组项目「龙女仆」制作的角色模型资源包。

项目设定中，玩家把已驯服的冰与火之歌（Ice and Fire）龙，通过道具转生为人形龙娘；她保留龙的元素、成长与力量，同时具备陪伴与工作的能力。本仓库提供这套设定下**由幼小到长大**的五阶段人形外观，格式为 [Yes Steve Model](https://yesstevemodel.github.io/wiki/intro/)（YSM）自定义模型，可直接放入 YSM 模组使用。

三种元素（火 / 冰 / 雷）× 五个成长阶段 = 15 套模型，每套四配色，合计 60 种外观。

## 每套文件夹里有什么

| 路径 | 说明 |
| --- | --- |
| `ysm.json` | 模型清单：名称、提示、作者、配色与附加设置 |
| `models/main.json`、`models/arm.json` | 主体模型与**独立第一人称手臂** |

| `controller/dragon_flight.json` | 飞行动画控制器 |

| `*署名与许可*.json` | 改模来源与原始署名、许可记录 |

阶段一、二为幼小体型，阶段三起加入更大体量的翼、尾与衣装；阶段三至五另含改模所沿用的女仆动作控制器与音效资源。

## 模型功能

- **表情与眨眼**：眼睛（默认 / 哭哭 / 闭眼 / 屑 / 晕 / 左右单眼）与嘴巴（默认 / w / ∧ / ww / 流口水）可切换，含眨眼与睡眠闭眼。
- **头发与视线**：头发物理摆动、发根随头部转向，眉毛与发色按配色区分。
- **尾巴**：行走甩尾、步频带动、潜行时尾摆；睡眠与游泳状态与其他动作隔离。
- **第一人称**：独立手臂模型，空手与持物视角共用主体贴图。
- **睡眠**：玩家普通床的睡眠定位与睡姿，各阶段保留自身体型；该位移不作用于女仆龙床。
- **附加动作**：打招呼、鼓掌、卖萌，以及女仆（TLM）与 CarryOn 的兼容动作。
- **飞行**：`dragon_flight` 控制器提供飞行状态切换。

## 安装与使用

1. 安装 [Yes Steve Model](https://yesstevemodel.github.io/wiki/install/) 模组（建议 2.2.2 及以上，本项目按 2.6.5 整理）。
2. 游戏内按 `Alt Y`（Fabric 版为 `Y`）打开模型选择界面，点击「打开模型文件夹」。
3. 将本仓库的每个模型文件夹**整个**放入该目录，每个文件夹是一套独立模型。
4. 执行 `/ysm model reload` 重载模型（需要 OP 权限），再在模型界面中选择。

单人游戏直接可用；多人服务器需要服主在服务端安装。模型仅包含 YSM 资源，不包含 YSM、Ice and Fire、TLM 等模组本体，也不包含「龙女仆」模组的程序部分。

## 加密模型包（`ysm/`）

`ysm/` 目录是同一批模型的加密单文件版本，每个文件对应上面表格里的同名文件夹（YSM 的模型 ID 就是文件名）：

- `dragon_maid_stage1.ysm` … `dragon_maid_stage5.ysm`：火龙阶段 1–5
- `dragon_maid_ice_stage1.ysm` … `dragon_maid_ice_stage5.ysm`：冰龙阶段 1–5
- `dragon_maid_lightning_stage1.ysm` … `dragon_maid_lightning_stage5.ysm`：雷龙阶段 1–5

用法与文件夹版本相同：把 `.ysm` 整个放进 YSM 模型文件夹（`Alt Y` → 打开模型文件夹），执行 `/ysm model reload`，无需解压。

- 由 YSM 2.6.5 的 `/ysm export` 导出，单个文件已包含模型、全部动画与控制、四配色贴图、作者头像、语言文件与显示名称、提示。
- `.ysm` 不能还原成可编辑工程，也不能再二次修改；要继续改模型请用上面的文件夹版本。
- `.ysm` 只向下兼容：在 2.6.5 导出的文件，放到更旧版本的 YSM 上可能无法加载。
- 导出时 YSM 会把动画合并进单个动画文件，并重新编码贴图与头像（解密后体积明显小于原图）；需要原图或原始文件结构时请用文件夹版本。
- 本次 15 个文件已验证：用 YSMParser 解密复核结构完整，并在 YSM 2.6.5 独立服务端载入后执行 `/ysm model reload`，全部正常加载。
